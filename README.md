# 로또 렌즈 · Lotto Lens

로또 6/45 복권의 당첨확인 QR을 읽고, 해당 회차의 당첨번호와 구매한 모든 게임을 비교하는 GitHub Pages 웹앱입니다.

## 기능

- 후면 카메라 QR 인식, 사진 QR 인식, QR 주소 붙여넣기
- 회차별 당첨번호 6개와 보너스 번호 표시
- 상단 당첨번호 클릭 시 동행복권의 해당 회차 추첨결과를 새 창으로 열기
- A~E 게임의 일치 번호·보너스 번호 강조, 게임별 등수와 회차별 당첨금 표시
- 추첨 전·결과 데이터 미갱신·조회 실패를 미당첨과 구분
- 화면 확인용 가상 샘플 복권 (실제 구매 복권과 구분)
- 복권 QR과 사진을 서버에 전송하거나 저장하지 않음
- 1~1244회 공식 당첨번호 포함 (2026-10-05 최초 확보)

## 개발

Node.js 22.12 이상 또는 24 권장.

```sh
npm ci
npm run dev
npm test
npm run build
```

카메라는 HTTPS 또는 localhost에서 동작하며 브라우저의 카메라 권한이 필요합니다. 휴대전화에서 HTTP 개발 서버의 LAN 주소에 접속하면 사진 인식만 사용할 수 있습니다.

## GitHub Pages

저장소 Settings → Pages → Source를 **GitHub Actions**로 설정합니다. main에 push하면 검사와 빌드 후 배포됩니다. 하위 경로에서도 실행되도록 Vite base는 `./`입니다.

매주 토요일 21:15·22:15·23:15 (한국 시간), 다른 요일 09:15에 공식 데이터 갱신과 재배포를 시도합니다. GitHub의 예약 실행은 지연될 수 있으며, 공용 저장소는 장기간 활동이 없으면 예약이 비활성화될 수 있습니다. Actions → Publish Lotto Lens → Run workflow로 직접 갱신할 수도 있습니다.

```sh
npm run data:update
```

공식 사이트의 공개 회차 조회 응답을 검증하고 같은 사이트에서 제공할 `public/draws.json`을 생성합니다. 브라우저에서 외부 API를 직접 호출하지 않습니다. 누락·중복·번호 범위·추첨일·보너스·당첨금·이전보다 적은 회차 응답은 거절하며, 실패 시 기존 파일과 기존 배포를 유지합니다. 공식 응답 형식이 변경되면 `scripts/update-draws.mjs` 수정이 필요합니다.

## QR 형식과 확인 범위

동행복권 공식 QR 화면의 공개 처리 코드와 대조한 79/87자 형식을 지원합니다: 회차 4자리 + `[msqn]`와 숫자 12자리로 된 게임 칸 5개 + 메타데이터 10/18자리. `n`은 미구매 게임으로 생략합니다. 공식 QR 호스트와 이전 모바일 호스트를 허용합니다. QR은 복권 진위 또는 지급 가능 여부를 인증하지 않으며 실물과 당첨번호를 대조해야 합니다.

공식 출처:
- https://www.dhlottery.co.kr/lt645/winNumber
- https://www.dhlottery.co.kr/lt645/selectPstLt645Info.do?srchLtEpsd=all
- https://qr.dhlottery.co.kr/

실제 Android·iPhone 카메라와 실물 복권의 기기 검증은 별도로 필요합니다. 자동 검사는 QR 파싱, 전체 당첨 등수, 보너스 분리, 과거 회차 당첨금, 추첨 전 구분, 데이터 무결성을 다룹니다.
